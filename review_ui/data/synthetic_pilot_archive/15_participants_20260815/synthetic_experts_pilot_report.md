# HyperTrace Synthetic Expert Pilot

> This is a software simulation for front-end and metric validation. It is not human-subject evidence and must not be presented as a CHI user study.

## Protocol

- 15 synthetic participants (`RE-01`-`RE-15`); 5 per interface condition.
- 10 trials per participant; the formal 24-case package and its hidden labels were used.
- The three primary outcomes are accuracy, erroneous-recommendation rejection, and appropriate reliance.
- Latency and confidence are secondary behavioral checks; questionnaire items are retained only as pilot signals.

## Results

## Interpretation boundary

The condition differences are generated by the simulation policy, not measured user effects. Use this report to verify data flow, export fields, and planned analyses only. Replace it with recruited risk-review participants before making any CHI claim.
