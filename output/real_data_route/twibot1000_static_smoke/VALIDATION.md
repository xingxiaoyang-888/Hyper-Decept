# TwiBot-22 真实数据路线跑通记录（Smoke Test）

日期：2026-07-28

## 路线边界

```text
TwiBot-22 原始数据
  -> 固定账号抽样与静态数据适配
  -> 多模态特征提取
  -> 二分类检测 + SHAP
  -> 预测 bot 子图的 Louvain 团伙发现
  -> HGT + Poincaré + DPMM 角色发现
```

本路线不经过 DeepPersona、MultiAgent4Collusion、LLM Agent、推荐系统或时间步仿真。

## 跑通结果

- 输入：1000 个真实账号，500 human、500 bot。
- 二分类：Accuracy=0.729，ROC-AUC=0.7856，预测 bot=489。
- 图：原始图 4006 节点/3739 边；余弦增强后 4352 节点/84651 边。
- 团伙：预测 bot 子图 489 节点，Louvain 得到 4 个非孤立社区。
- 角色：1000 个账号均得到角色输出；Smoke Test 只训练 HGT 2 epochs。
- 白盒输出：已生成 SHAP summary、逐账号概率、节点特征、团伙和角色文件。

## 不能作为正式论文结果的原因

- 本次为均衡抽样，而不是 TwiBot-22 的自然类别比例或官方完整 split。
- 每个账号最多编码 5 条推文。
- `psychology_mode=off`，8 个心理维度均为 0；团伙心理画像因此无效。
- HGT 仅运行 2 epochs，角色名称和分布只用于验证代码链路。
- 余弦相似边（80913 条）远多于原始关系边，正式实验必须做原始图/增强图消融。

## 人为可控项（不是仿真设置）

### 数据处理

- 核心账号数与抽样 ID；本次 1000。
- human/bot 抽样比例；本次人为平衡为 500/500。
- `random_seed=42`。
- `max_actions=50`、`max_follows=100`。
- 单条推文字符上限 280、单账号推文总字符上限 5000。
- 是否保留边界账号和哪些关系类型映射为 follow/post/like/reply。

### 检测与解释

- 每个账号最大编码推文数；本次 5。
- 心理引擎模式；本次 off，正式实验应为 full 并保存模型版本。
- 文本编码模型与 PCA 维数。
- 余弦建边阈值；本次 0.7。
- XGBoost 超参数、交叉验证折数、SMOTE 和分类阈值。
- Louvain 随机种子、是否移除孤立点。
- HGT 层数、隐藏维、注意力头、epoch、负采样和 Poincaré margin。
- DPMM 最大分量数与先验。

这些设置会影响检测结果，但都属于数据抽样、预处理或算法超参数。真实数据路线不存在 Agent 人数、时间步、推荐器、攻击策略、好坏 Agent 分工、LLM 温度或平台干预等仿真设置。
